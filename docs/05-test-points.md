`Criterion` holds the acceptance criterion's stable `AC-nn` ID from
`docs/02-functional-spec.md` §6 (or `—` for a check that is not
criterion-bound). `Coverage` holds exactly one of: `driven`, or one of the
eight delegation tags from `references/test-automation.md` (`CREDENTIAL`,
`HARDWARE`, `ASSISTIVE-TECH`, `JUDGMENT`, `EXTERNAL-APPROVAL`,
`PLATFORM-IMPOSSIBLE`, `PRODUCTION-RISK`, `NO-EXECUTION`) — never free text.

`Red first` holds exactly one of five values (`references/test-automation.md`,
"When the test is written"; project card `Test-first policy: pure-logic`,
D-036): `observed` — the test was run before the code existed, failed for
the absent behaviour, and its one-line failure output is in this row's
evidence cell; `n/a — policy` — the card's policy does not cover the row;
`n/a — out of scope` — UI markup, framework glue, exploratory third-party
integration or one-line configuration; `n/a — predates` — the row existed
before the project adopted the policy (it is not retroactive: every row
above this note's adoption date, 2026-10-06, carries it); `n/a — delegated`
— the row's `Coverage` is a delegation tag. The `Evidence` cell of every
new row also carries the `scope:` line printed by
`scripts/keel-affected-tests`.
